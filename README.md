## 🎬 Acerca del Proyecto

**SanTV_App** es una aplicación móvil de streaming diseñada para brindar una experiencia de entretenimiento fluida, segura y escalable. Cuenta con un ecosistema completo que conecta un frontend multiplataforma con un backend robusto en Node.js y persistencia de datos no relacional.

> 💡 *Diseñado para ofrecer alta disponibilidad, seguridad en la autenticación y un reproductor de contenido ágil.*

---

## ✨ Características Principales

- 🔐 **Autenticación y Seguridad:** Registro e inicio de sesión seguro con cifrado de contraseñas y JWT (JSON Web Tokens).
- 🎬 **Catálogo e Interfaz Didáctica:** Exploración de contenido, categorías y detalle de publicaciones.
- 👤 **Gestión de Perfiles:** Control de usuarios y preferencias.
- ⚡ **API Restful:** Comunicación rápida e integración limpia entre Flutter y el servidor.

## 🛠️ Arquitectura y Tecnologías

| Componente | Tecnología | Descripción |
| :--- | :--- | :--- |
| **Frontend** | Flutter / Dart | Aplicación móvil multiplataforma fluida y reactiva. |
| **Backend** | Node.js / Express | Servidor REST API encargado de la lógica y la seguridad. |
| **Base de Datos** | MongoDB | Base de datos NoSQL para almacenamiento flexible de usuarios y contenido. |
